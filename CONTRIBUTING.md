# Contributing

Bug reports and focused pull requests are welcome.

1. Do not include server backups, player data, credentials, addresses, logs, or proprietary plugin binaries.
2. Keep Paper API dependencies in `provided` scope.
3. Add or update tests for behavioral changes.
4. Run `mvn --batch-mode clean verify` before submitting a change.
5. Explain compatibility and migration impact in the pull request.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
